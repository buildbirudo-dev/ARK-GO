💾 保存・データ移行

この端末に保存

通常の入力はブラウザのローカル保存領域に自動保存されます。ブラウザのデータ削除や端末変更に備えて、バックアップを作成してください。

🔐 保存について

  • データはこのブラウザ内に保存され、別の端末やブラウザとは自動同期されません。
  • 共有端末では個人情報や公開前の原稿を保存しないでください。
  • バックアップJSONには下書きなどの入力内容が含まれることがあります。保管先に注意してください。

📱 iPhoneで使う

  1. GitHubに index.html として配置します。
  2. GitHub Pagesを有効にすると、ブラウザで開けるURLを作れます。
  3. Safariの共有メニューから「ホーム画面に追加」を選ぶと、アプリのように開きやすくなります。

GitHub Pagesは公開用の静的ホスティングです。リポジトリの公開設定や機密情報の扱いを確認してから利用してください。
