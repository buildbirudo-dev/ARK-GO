# ARK GO

ARK GO は、note 運用（企画・編集・分析・法務・開発）を小さなチームで回すための、無料優先ブラウザ型ツールです。
単一の HTML ファイルで動作し、ローカルの Ollama を使った AI 支援や GitHub public repo からの情報取得が可能です。

---

## 主な機能

- 投稿予定 3 本の管理（タイトル・予定日・進捗・メモ）
- 記事エディター（下書き保存、文字数カウント、TXT 書き出し、コピー）
- AI 支援（ローカル Ollama を使った記事候補、タイトル／見出し／導入文／レビューコメントの生成）
- note 実績の手動記録（インプレッション・PV・スキ・売上）と CSV 出力
- 公開前の法務チェックリスト（開示・引用・画像・個人情報・表現）
- GitHub 公開リポジトリの README / Issues / PR を読み取り、要点を AI に整理
- アフィリエイト導入支援
  - 開示テンプレの自動挿入
  - リンクテンプレ管理（localStorage）
  - UTM 付きリンク生成フォーム
  - 収益データ入力・CSV 出力

---

## すぐに始める（セットアップ）

1. このリポジトリをローカルにクローン、または index.html を直接ブラウザで開きます。
2. （AI機能を使う場合）ローカルで Ollama を起動し、モデルを準備します：
   - ollama pull llama3.2
   - ollama run llama3.2
3. ブラウザで index.html を開き、画面右上から各画面へ移動して操作します。

注意: AI 機能はローカルの Ollama へ HTTP で問い合わせます。Ollama が動作していない場合は生成機能はエラーになります。

## 無料でできることと制限

- 無料で可能
  - GitHub public README の読み取り
  - ローカルの Ollama を使った生成（ローカル実行が必須）
  - localStorage による保存、CSV / TXT のエクスポート
- 制限・未実装
  - note への自動投稿（未実装）
  - private GitHub リポジトリの自動読取（PAT が必要）
  - サーバー側での同期や端末間の自動同期

## アフィリエイト運用の流れ（推奨）

1. 記事に開示（ディスクロージャー）を必ず入れる。テンプレは設定画面で編集可。
2. 記事内リンクに UTM を付与して配信（UTM ルールを統一すること）。
   - utm_source=arkgo
   - utm_medium=note
   - utm_campaign=記事タイトル
   - utm_content=リンクラベル
3. GA4 で `affiliate_click` / `purchase` を計測し、記事別の流入・成約を把握する。
4. 収益は ARK-GO の「収益入力」画面で手動登録し、CSV 出力して分析する。

注意点: アフィリエイトの API キーやシークレットは localStorage に保存しないでください。公開鍵のみ（提携ID等）を設定し、機密情報は安全な場所に保管してください。

---

## GitHub 連携（public 情報の読取）

- public README を取得し、AI に渡して記事候補の生成ができます。
- public Issues / Pull Requests の要点を取得して、開発の動きやユーザーニーズを企画に活用できます。
- private リポジトリや書き込み操作（issue 作成・PR 作成等）は GitHub PAT と追加実装が必要です。

---

## データの保存形式

- アプリケーションデータはすべてブラウザの localStorage に保存されます。
- 主要キー例：
  - ark_go_v3_state （アプリ本体の状態）
  - ark_affiliate_config （アフィリエイト設定）
  - ark_affiliate_records （収益データ）
  - ark_idea_cache （AI 生成履歴）

## 開発者向け（実装メモ）

- AI 呼び出しはローカルの Ollama API を想定（http://localhost:11434/api/generate）
- GitHub API は公開情報取得にのみ使用（https://api.github.com/repos/:owner/:repo/readme など）
- UTM 生成・GA4 イベント送信・CSV 出力はクライアント側で完結します
