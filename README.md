# ARK GO

ARK GO は、note 運用とアフィリエイト運用をまとめて管理するための無料優先アプリです。

- 企画
- 記事作成
- 実績入力
- 法務チェック
- アフィリエイト運用
- GitHub public 情報の要点整理

を、1つのブラウザ上で管理できるように設計しています。

## 特徴
- スマホ対応
- 単一 HTML 構成
- ローカル保存
- AI 生成（Ollama）
- GitHub public README の自動読取
- UTMリンク生成
- アフィリエイト開示テンプレ
- 収益CSV出力

## 使い方
1. index.html をブラウザで開く
2. AI を使う場合は Ollama を起動
3. 投稿予定・記事本文・実績を入力
4. 公開前に法務チェック
5. 必要に応じてアフィリエイト設定を使う

## アフィリエイト運用の流れ
1. 記事本文に開示文を入れる
2. UTM付きリンクを生成して貼る
3. GA4 で affiliate_click / purchase を計測する
4. 収益データを記録する
5. CSV で分析して改善する

## 収益の扱い
- 収益は localStorage に保存されます
- 収益データは CSV で出力可能
- GA4 と並べて比較して記事ごとに改善する

## 注意点
- アフィリエイトに関する法務や規約は確認が必要
- 秘密情報を localStorage に置かない
- 開示文は必ず入れる
- 効果や評価を断定しない

## 開発メモ
- ローカル収集を主眼に置いています
- GitHub public 情報取得は無料範囲で利用
- note 自動投稿やサーバー連携は未実装です
