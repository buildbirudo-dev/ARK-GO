# ARK GO

ARK GO は、note 運用とアフィリエイト運用をまとめて管理するための無料優先アプリです。

- 企画
- 記事作成
- 実績入力
- 法務チェック
- アフィリエイト運用
- GitHub public 情報の要点整理

を、1つのブラウザ上で管理できるように設計しています。

## 特徴
- スマホ対応
- 単一 HTML 構成
- ローカル保存
- AI 生成（Ollama）
- GitHub public README の自動読取
- UTMリンク生成
- アフィリエイト開示テンプレ
- 収益CSV出力
- 下書き保存
- 生成履歴 / テンプレート / AI要約

## 使い方
1. index.html をブラウザで開く
2. AI を使う場合は Ollama を起動
3. 投稿予定・記事本文・実績を入力
4. 公開前に法務チェック
5. 必要に応じてアフィリエイト設定を使う

## AI 生成（Ollama） — 無料でローカル実行

ARK GO はローカルの Ollama を使った無料の AI 生成機能をサポートします。ブラウザ上からローカルのモデルに問い合わせて、記事のタイトル案・見出し・本文案・要約などを生成できます。

### 使い方（最短）
1. Ollama をインストールしてローカルで起動します。

```bash
ollama run llama3.2
```

2. リポジトリをクローンしてローカルサーバーを起動します。

```bash
git clone https://github.com/buildbirudo-dev/ARK-GO.git
cd ARK-GO
python3 -m http.server 8000
```

3. ブラウザで開きます。

```text
http://localhost:8000/index.html
```

4. ページ内の「AI生成（Ollama）」パネルで以下を行います。
- API エンドポイントを確認
- テンプレートを選んで適用
- プロンプトを調整して「AI生成」
- 生成結果を画面で確認
- 「本文へ挿入」で記事本文へ追加

### スマホから使う場合
- PC 側で Ollama を起動している状態にします
- スマホと PC を同じ LAN に接続します
- PC のローカル IP を確認して、パネルの API エンドポイントを変更します
  - 例: http://192.168.1.10:11434

### 主な機能
- ローカル Ollama への生成リクエスト
- プロンプトテンプレートの選択・編集
- 生成履歴の保存・ロード・挿入・エクスポート
- 下書き保存（localStorage）
- 簡易法務チェック
- 要約生成

### 注意事項
- この機能はローカル環境での利用を前提としています（Ollama の起動が必須）
- Ollama 自体や利用するモデルにより動作や出力が異なります
- 履歴・下書き等はブラウザの localStorage に保存されます
- 機密情報は保存しないでください
- OpenAI 等のクラウド API を使う場合は API キーと課金管理が必要です

### トラブルシュート
- Ollama が応答しない場合

```bash
curl http://localhost:11434/api/tags
```

このコマンドが返らない場合、Ollama が起動していないか、エンドポイントが違います。

- スマホから接続できない場合
  - PC のローカル IP を正しく指定しているか
  - 同じ Wi‑Fi に接続しているか
  - PC のファイアウォールでポートがブロックされていないか

## アフィリエイト運用の流れ
1. 記事本文に開示文を入れる
2. UTM付きリンクを生成して貼る
3. GA4 で affiliate_click / purchase を計測する
4. 収益データを記録する
5. CSV で分析して改善する

## 収益の扱い
- 収益は localStorage に保存されます
- 収益データは CSV で出力可能
- GA4 と並べて比較して記事ごとに改善する

## 注意点
- アフィリエイトに関する法務や規約は確認が必要
- 秘密情報を localStorage に置かない
- 開示文は必ず入れる
- 効果や評価を断定しない
